# Border Guard Training – Technical Documentation & Instructional Materials

This repository contains a collection of technical documentation and instructional materials that I created during my work at the **Border Guard Training Centre in Kętrzyn (Poland)**.

The materials were developed for international groups of Border Guard officers from:

- **Lithuania**
- **Latvia**
- **Estonia**
- **Ukraine**
- **Finland**

---

##  About the Repository

The repository includes examples of:

### 1. Technical Instructions for Specialized Equipment
Documentation created for training purposes, covering the operation, servicing, and safe handling of devices used by Border Guard units, such as:

- **EOD / pyrotechnic robots**
- **Specialized detection procedures**

These materials were designed to be clear, structured, and suitable for multilingual training environments.

---

### 2. Standard Operating Procedures (SOPs)
Examples of precise, procedure‑oriented documents used during training, including:

- **Step‑by‑step operational procedures**
- **Safety protocols**
- **Procedures for narcotics detection and evidence handling**
- **Scenario‑based workflows for field operations**

These documents support both classroom instruction and practical exercises.

---

### 3. Training Materials for International Courses
The repository also contains:

- Instructional content prepared for **multinational training groups**
- Materials available in **English and Polish**
- Examples of **presentations, structured guides, and e‑learning content**

---

##  Purpose

This repository showcases selected examples of my work as a:

- **Technical Writer**
- **Technical Translator**
- **Training Materials Developer**

It demonstrates my experience in producing clear, accurate, and operationally relevant documentation for uniformed services and international training programs.
